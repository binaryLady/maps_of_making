Embed config — voor devs
// mapsofmaking.org embed URL
preset=vlaio-ziezo
country=BE
bbox=2.28,50.28,6.09,51.44
accent=080A80
mode=light
partner=vlaio
Workflow:
1. MoM levert een publiek ?preset=vlaio-ziezo URL
2. ZieZo plakt de <iframe> in de activiteitenpagina
3. accent=, mode= en partner= sturen branding
4. MoM-engine blijft ongewijzigd — enkel chrome verandert
